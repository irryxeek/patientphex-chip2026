# 神经候选、语义归一化与患者证据复核实验协议

2026-10-22，读取本轮开发预测结果前制定。对照为 `runs/recall_optimization_v1/`。

## 设计与边界

结合 AutoPCR/LEAP 的候选检索、同赛题多源融合和文档关系证据思路，执行三个模块：

1. BioLinkBERT-base 做 BIO 表型跨度识别，仅在官方训练文献上微调；加入现有词典候选。
2. 冻结 SapBERT，用固定 HPO 的名称及 EXACT 同义词建立归一化向量索引；先用训练折别名精确匹配，
   再用候选相似度、前两名差距筛选。原文跨度、否定和本体版本约束保持。
3. 另一个 BioLinkBERT-base 分类头读取患者—表型证据包，学习患者归属；与现有梯度提升关系概率融合。
   证据包只使用原文、给定患者提及和预测实体；标注关联仅用于训练标签。

两个预训练模型均约 0.11B，公开预训练来源分别为 PubMed 文本与引用关系、UMLS 同义概念配对。
不使用已在全部 80 篇 PatientPheX 上拟合的冠军权重、外部人工表型标注或外部病例答案。
本轮先执行小编码器方案，8B 生成模型不是本轮必要依赖。

预训练 revision：

- BioLinkBERT-base：`b71f5d70f063d1c8f1124070ce86f1ee463ca1fe`。
- SapBERT-from-PubMedBERT-fulltext：`090663c3ae57bf35ffe4d0d468a2a88d03051a4d`。

权重和中间张量写入既有 SSD 根下的独立目录，记录下载哈希、参数量、训练文献及设备。
不会终止现有 GPU 服务。GPU 分配确认前只执行 CPU 准备；模型代码同时支持 CPU。

## 固定训练设置与候选

保持原 64/16 篇分组及 64 篇内原四折。每折的训练别名、NER 和关系模型只使用另外三折。
NER：随机种子 42，4 epochs，AdamW，学习率 3e-5，weight decay 0.01，最大 384 tokens，
重叠 64 tokens，batch 8；全量子词监督，跨窗口截断实体不作为完整实体输出。
关系编码器：随机种子 43，3 epochs，学习率 2e-5，最大 512 tokens，batch 8；
每个患者—概念最多选取三处表型证据，保留患者与其他人的区别，允许多人同有表型及空集合。
实际训练样本、不可对齐标注及截断数单独记录，不改写官方标注。

NER 的新增跨度需满足原文和词元边界检查。相同跨度的训练折精确别名优先；其余使用 SapBERT
对 HPO 名称/EXACT 同义词编码的 CLS 向量，经 L2 归一化后按余弦检索。
前两名按不同 HPO 概念计算差距，不能把同概念的两个同义词当成歧义。
新增连续跨度仅接受单 ID 或训练折已见的复合 ID，不生成新的疾病推断表型。

预定实体候选配置按以下顺序：

- 冻结原版。
- `augment`：保留原版，增加不重叠神经跨度。
- `replace`：允许较长神经跨度替换完全被其包含的词典跨度；部分交叉仍拒绝。

新增神经跨度的 BIO 概率阈值固定 0.50；对两种合并策略，各比较检索相似度
0.80/0.85/0.90 和不同概念差距 0.00/0.03，共 12 个配置。
精确匹配训练折别名的跨度不受语义相似度阈值影响。
实体方案先以四折合并的 Mention/Document F1 均值选择；完全同分优先原版及更早配置。

在选定实体方案下训练证据关系模型，比较神经概率权重 0/0.25/0.50/0.75/1.0，
关系阈值 0.20/0.35/0.50/0.65。原版完整系统额外作为保留候选。
最后按四折合并的四指标均值选择唯一完整配置，完全同分优先原版。
这些折外预测用于选择配置，不声称是未经方法选择的无偏性能估计。

## 外层验证、交付与失败处理

冻结实体和关系 selection 后，才对 16 篇开发文献计算本轮指标。
采用条件：总分严格超过当前本地 59.9128，且患者 Macro 不低于当前 38.5466；以保存的未舍入值比较。
同时给出仅新实体配旧关系模型的消融、逐文献差值、空/稀疏患者分组及配对文献 bootstrap。
不根据外层结果重新挑阈值，不因论文推荐某方法就推翻旧实验的未采用结论。

通过采用条件后，用全部 80 篇重新拟合并生成 A/B。核验覆盖、原文跨度、本体、模型及输入哈希，
在独立进程重载复算，之后沿用本任务已有提交授权进行一次赛后评测。
