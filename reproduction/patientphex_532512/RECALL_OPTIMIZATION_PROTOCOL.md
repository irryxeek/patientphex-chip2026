# 实体召回优化协议

2026-10-21，第二轮候选实验结果观察前冻结。上轮集合实验的训练内选择仍为原模型，
本轮继续以 optimization_v1 为对照；不根据上轮外层消融的较高分更换关联器。

沿用原 64/16 篇文献划分、四个 PMID/全文分组、原版冻结 enhanced.py、原评分程序、
HPO 2026-06-23、过滤阈值 0.50、词形和文内缩写。只使用官方训练数据与随包本体。

## 预定改动与比较

- 补充本体 BROAD/NARROW/RELATED 同义词作为待检验候选；只接受归属唯一、未覆盖原别名的表述。
  这些 scope 不保证概念等价，因此须接受训练内过滤及独立文献验证，不能当作确定事实。
- 拼写与连写归一化：保守英美拼写替换、现有单复数转换、去除 token 间空格。
- 词序归一化：相同内容词集合，最多 8 个内容词、12 个原文 token；
  仅跳过固定功能词 of/the/a/an/in/is/are/was/were，不跳过否定词、and/or。
- 新匹配不跨句或逗号等标点，原文连续跨度保留原 Unicode offset。
- 新候选按匹配键在各折拟合文献中计算边界和 ID 精确率，低于 0.50 的键拒绝；
  未在拟合文献出现的键保留。开发和推理标签不参与过滤。
- 默认仅补充与原实体不重叠的候选；另比较明确预定的最长跨度替换消融。

八种实体配置按顺序为：原版、仅补充同义词、仅拼写/连写、仅词序、拼写加词序、
三者联合、三者联合加最长跨度、词序加最长跨度。
每种使用原梯度提升关联模型和参数，以其拟合内候选训练，比较 0.20/0.30/0.40/0.50/0.60
五个关系阈值，共 40 个配置。新增匹配不改变关系特征、否定逻辑或评分定义。

## 选择和采用

以四折合并的四指标均值选择唯一最终候选；相同得分优先原版及更早的配置/阈值。
冻结 selection.json 后才读取本轮外层标签。外层只验证最终候选、冻结原版，以及
“新实体加旧关联模型”的解释性消融，不从外层结果改选候选。

采用条件：外层总分严格高于 57.69321349，患者 Macro F1 不低于 37.07262763。
记录逐文献差异、空/少/多表型患者分组、新增与替换实体的 TP/FP/FN 变化。
配对文献 bootstrap 10,000 次、seed=42；这是反复观察过的开发比较，不能称独立测试或无选择偏差。

若通过，使用全部 80 篇训练文献重拟合并导出 A/B；覆盖、偏移、本体、源哈希、独立进程回放
全部通过后才提交，并据真实线上结果判断是否替代当前线上最优版本。
否则保留旧默认模型和完整失败记录。全部工作在 CPU 完成。
