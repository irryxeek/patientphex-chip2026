# 交叉拟合候选与患者集合决策实验协议

2026-10-21，运行结果观察前冻结。沿用 optimization_v1 的实体配置、冻结增强代码、
64/16 篇文献划分、4 个内层文献组及本地参考评分程序；不引入上轮未采用的状态特征。

## 比较内容

关系模型仍使用原 HistGradientBoostingClassifier 参数。比较两种训练候选：

- in_sample：复用已冻结的原关系模型，候选由见过拟合文献的词典产生。
- crossfit：每个内层训练集合再做三折文献分组，以未见过目标文献标签的抽取器产生关系训练候选。
  当前内层验证文献不参与子折的任何拟合；外层开发集始终隔离。

每种模型比较以下预定输出决策，所有阈值只根据内层合并患者 Micro/Macro F1 均值选择：

1. 全局阈值 0.20、0.30、0.40、0.50、0.60。
2. 证据约束：有明确规则、独占同句或章节归属支持的候选阈值 0.20，其余为 0.40、0.60、0.80。
3. 患者集合门控：没有被选中的强证据候选且最高分低于 0.40、0.60、0.80 时，输出空集合；其余使用 0.20。
4. 患者相对阈值：max(0.20, 患者最高分 × 0.50/0.75)。
5. 原实体关联规则，作为保守对照。

共 14 种决策，每种关系模型使用相同预算。相同得分优先原模型、较早列出的简单决策。
本轮不训练额外校准器，不将金标准集合大小、健康状态或患者 ID 作为门控输入。
候选分数是分类器输出，不能未经校准就解释为准确的事件概率。

## 预定消融和选择

内层确定最终候选后，才读取本轮外层标签。保留：原版、仅交叉拟合（固定 0.20）、
仅集合决策（原模型）、交叉拟合加集合决策，以及各模型最优全局阈值对照。
最终候选只依据内层选择，不能在看完外层后改挑表现更高的另一个消融。

默认替换条件：外层四指标均值严格高于原 57.69321349，且患者 Macro F1 不低于原 37.07262763。
逐文献、空/非空及少/多表型患者的收益必须同时记录，区分是否仅由一篇文献主导。
配对文献 bootstrap 使用 10,000 次、seed=42；这是经过多轮观察的开发比较，区间不覆盖方法选择偏差。

若通过上述条件，使用全部 80 篇官方文献拟合选定方案并导出 A/B；交叉拟合方案的全量关系训练
使用 80 篇内部的四折候选。否则保留当前线上版本，完整保留本次失败尝试。
生成文件需通过覆盖、偏移、固定 HPO、源文件哈希和独立进程重载检查后才可用于提交。

全部工作在 CPU 完成；不启动 GPU、收费 API 或在线实验跟踪。
