## 结论

28 个预定配置在 64 篇训练文献的四折验证中，仍选中原关系模型和全局阈值 0.20。
最终候选在 16 篇开发文献上与当前版本完全相同，总分仍为 **57.6932**。
本轮不更换模型、不重新导出或提交同一文件；未采用的模型、预测和诊断均保留。

交叉拟合在开发集单项消融中达到 58.8073，但训练内表现下降。
按照事先固定的规则，不能看完外层结果后改挑该方案。
这提示它可能存在折间差异，需要新的分组验证证据，不能仅据该开发消融宣称稳定提分。

## 候选分布诊断

每个内层训练集合为 48 篇；其交叉拟合候选由三个 32/16 子折生成。
各子折验证文献不参与对应别名学习，当前外层验证文献也不参与任何子折拟合。
每个子折的文献 ID、全文指纹及禁止进入的验证文献保存在 `inner/fold*/crossfit/folds.json`。

拟合内候选的 Mention F1 为 90.52–91.28；交叉拟合候选为 69.61–71.18。
交叉拟合关系训练行数和正例数均减少。这证实两类训练候选确实不同，
但不证明分布对齐会带来更好的分类器。
相同 4,055 个折外验证候选上的 Brier 从 0.113963 变为 0.119040，反而略差。
分数未做概率校准，不能直接当作可靠事件概率。
