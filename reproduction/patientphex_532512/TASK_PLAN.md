制定日期：2026-10-20。范围包含全文表型识别与给定患者表型关联两个子任务。
已完成阶段 1 的工程兼容、阶段 2、阶段 3 的 CPU 优化和阶段 4 的实际线上评测。
2026-10-21 完成两轮共 68 个预定配置比较，CPU 方案本地 59.91、官方赛后 0.6258642。
2026-10-22 获 GPU 6/7 授权后完成神经方案：四折选择、外层验证、80 篇全量训练、A/B 独立复算
及一次赛后评测。当前本地总分 **67.21**，官方赛后总分 **0.6567391667419546**，
比前版提高 3.0875 个百分点。当前模型为 `runs/neural_frontier_v1/full/`。
最新结果与复现方式见 [NEURAL_FRONTIER_REPORT.md](NEURAL_FRONTIER_REPORT.md)，
预定协议见 [FRONTIER_EXECUTION_PROTOCOL.md](FRONTIER_EXECUTION_PROTOCOL.md)。

## 目标与约束

交付一套可复现的训练、推理、验证和提交流程，以及 A/B 输入的 UTF-8 JSONL 预测。
优化目标为 mention F1、document F1、patient micro F1、patient macro F1 的等权平均。
真实在线分数与本地参考分数分别记录。

依据：[官方任务说明](http://cips-chip.org.cn/2026/eval1)、
[组织方仓库](https://github.com/DUTIR-BioNLP/PatientPheX)、
[天池比赛](https://tianchi.aliyun.com/competition/entrance/532512)及随包 README。
只使用官方 80 篇标注训练文献；A 榜 20 篇和 B 榜 100 篇不含答案。
HPO 固定为 2026-06-23 的 HP:0000118 分支。模型规模不超过 10B；
外部资源须公开并记录来源，不引入外部人工标注表型数据。
当前天池接口显示赛后评测，正式 B 榜已结束；后续提交属于当前开放阶段。

## 阶段 1：数据和评分协议

1. 保留下载文件及 SHA256，检查字符偏移、文献/患者完整性与集合重叠。
2. 区分金标准读取和提交校验：金标准中的重复项、旧 ID、非标准标记进入审计，
   提交结果仍要求合法的 HPO、准确字符边界、无重复、覆盖全部文献与指定患者。
3. 对固定 HPO 的 alt_id 和唯一 replaced_by 建立有出处的训练映射；
   无可靠映射的训练别名暂不使用，不猜测六位 ID 或 MESH 到 HPO 的关系。
4. 本地评分保留金标准 ID，不通过删除难例或修正答案提高分数。
   复合患者关联同时报告拆分口径与原始字符串口径的敏感性结果。
   未公开的评分细节明确列入限制。

验收：正式数据可完整读取，异常有逐项记录；提交校验仍能拒绝错误预测；
偏移、否定、复合 ID、空集合和数据泄漏检查有 CPU 回归测试。

## 阶段 2：第一轮可复现基线

1. 仅在官方训练集内按 PMID/相同全文分组，以 seed=42 固定约 64/16 篇训练/验证。
   先冻结划分，禁止使用验证别名构建模型。
2. 在同一划分比较 HPO 词典与 HPO 加训练别名两个基线。
   保存四项 F1、P/R、TP/FP/FN、逐文献及逐患者诊断、运行时间、源代码和输入哈希。
3. 表型抽取保留原始 Unicode 字符偏移；否定表型不进入患者正例集合。
   患者归属从显式提及、同句关系和段内指代开始，每条关联保留可追溯证据。
4. 分开统计边界错误、归一化错误、未召回实体及患者归属错误，
   区分抽取召回限制与已有正确概念的归属损失。

验收：留出集完整预测且无训练重叠；分数可重新计算；全量训练后生成 A/B 初版文件，
两份文件均通过严格校验。它们是可运行基线，不代表最终优化效果。

## 阶段 3：依据验证错误改进

按收益和成本顺序开展，每次只改变可解释的组件并保留旧结果。

| 组件 | 实施方法 | 验收依据 |
| --- | --- | --- |
| 实体候选 | 训练别名、词形变体、文内缩写；避免跨句匹配 | mention/document 召回和精确率 |
| 概念规范化 | 固定 HPO 候选检索，结合上下文消歧，保留复合概念 | 边界正确样本的 ID 准确率 |
| 否定 | 句内否定范围、转折、列举和历史描述检查 | 否定误判及正例召回 |
| 患者归属 | 文献分节、患者提及链、跨段证据；监督关系分类或受约束语言模型 | patient micro/macro F1 |
| 神经增强 | 评估 Qwen3-8B 或更小公开模型进行候选确认与关系抽取；必要时仅用官方训练集微调 | 同划分增益、耗时、显存、错误样本 |

阈值和超参数优先在训练部分做内层分组验证；外层 16 篇是开发留出集，
反复查看后不得声称是未触碰测试集。增加模型复杂度须有同协议收益证据。
神经实验前重新核对可用 GPU 和占用，不沿用其他实验的设备许可或终止已有服务。
CPU 实体与患者关联优化已执行，补充状态特征方案因开发分数退步而未采用。
交叉拟合/集合决策比较未被训练内选择采用；第二轮实体召回优化已完成开发和官方 B 集核验。
所有旧结果与未采用尝试均保留，后续不据外层消融结果重新挑选第一轮方案。

## 阶段 4：交付与线上评测

1. 选定配置后使用全部 80 篇训练文献拟合，预测 A/B 数据；
   全部文献、患者 ID、字符边界、HPO 版本与 JSONL 编码通过检查。
2. 保存模型/配置、代码版本、依赖、资源来源、预测 SHA256 和复现命令。
3. 在天池当前可用阶段提交对应文件，记录实际回执、分数和失败信息；
   线上评分反馈用于核对协议，不能将本地分数写成天池成绩。
4. 整理技术说明、消融结果和已知失败模式。
