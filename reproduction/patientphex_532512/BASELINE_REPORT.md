# PatientPheX 首轮执行报告

2026-10-20。已完成数据兼容修复、真实留出验证、两种基线比较和 A/B 初版预测。
执行方案见 [TASK_PLAN.md](TASK_PLAN.md)。本报告所有分数都是本地参考评分，尚未在线提交。

## 实验设置

官方训练集共 80 篇。按 PMID 与相同全文分组，seed=42，留出比例 20%，
得到训练 64 篇、验证 16 篇；验证集有 54 位指定患者。
两种方法使用同一划分和评分程序，训练别名只从 64 篇拟合部分学习。
两者均为 CPU 词典方法，没有神经模型微调、GPU 推理或收费 API 调用。

HPO 使用随数据包提供的 2026-06-23 版本。方案一只使用名称与 EXACT 同义词；
方案二增加官方训练实体的表述。二者共享简单否定检测、同句及段内患者关联规则。

运行目录：`runs/baselines_v1/`。其中 `config.json` 在查看验证结果前保存划分、
输入哈希和比较方案；`source/` 保存运行时源代码。验证原文、标签、预测、证据、
逐文献/患者诊断与指标均已保存。完整实验耗时约 4.8 秒，不含此前的数据准备。

## 本地结果

数值均为百分制 F1；总分为四项 F1 的等权平均。

| 方法 | Mention F1 | Document F1 | Patient micro F1 | Patient macro F1 | 总分 |
| --- | ---: | ---: | ---: | ---: | ---: |
| 仅 HPO 词典 | 63.50 | 68.45 | 40.06 | 38.36 | 52.59 |
| HPO + 训练别名 | 65.06 | 69.59 | 41.08 | 38.93 | 53.66 |

训练别名方案的总分增加 1.07 点。按文献做 10,000 次配对 bootstrap（seed=42），
差值的 95% 百分位区间为 **[-0.77, 3.66]**，尚不能据此认定稳定优势。
训练别名方案自身总分区间为 [47.34, 60.31]。样本只有 16 篇，
区间不包含评分协议、标注歧义和方案选择带来的不确定性。
统计记录为 `paired_bootstrap.json`，聚合结果与原始指标完全一致。

## 数据兼容与评分边界

原始下载数据未被改写。金标准读取允许记录异常，提交文件继续使用严格校验。
官方训练集中 177 个多余重复患者关联按集合处理；32 个去重后的患者复合关联条目
（原始列表含 33 项）在主口径按 HPO 分量拆分，同时保留原始字符串口径作为敏感性分析。
以原始字符串评分时，训练别名方案总分为 **53.61**，仅词典方案为 **52.53**。

完整训练集中有 38 个实体 ID 分量不在固定版本的在用表型分支内。
拟合时，12 个实体可通过本体明确给出的 alt_id/replaced_by 转到有效概念；
22 个包含未解决分量的实体不用于学习别名，未尝试猜测六位 ID、MESH ID 或 `N` 的含义。
评估仍保留所有金标准分量，未把这些项从评价分母中删除。
重复实体按集合计数，只有 `NO` 作为否定，3 个辅助 `D` 标记按普通金标准处理并记录。

本地评分程序尚未与组织方程序做一致性校验。无 ID 实体的文档级处理、
辅助标记和复合患者关联的实际线上口径仍有不确定性。
本地结果不可替代天池成绩。

## 错误分析与后续顺序

训练别名方案在验证集的 mention TP/FP/FN 为 823/319/565，
患者关联 TP/FP/FN 为 137/62/331。

| 漏检类别 | 数量 |
| --- | ---: |
| 实体：无重叠候选 | 405 |
| 实体：有重叠但边界不同 | 117 |
| 实体：被误判为否定 | 23 |
| 实体：边界相同但 ID 不对 | 20 |
| 患者关联：概念未抽取 | 192 |
| 患者关联：概念已抽取但未归属给正确患者 | 139 |

训练别名提升了实体召回（50.58% → 59.29%），同时降低精确率（85.30% → 72.07%）。
因此下一轮先在训练部分做内层验证，筛选可靠别名、补充文内缩写和词形候选，
再改进跨段患者指代与关联。后续神经方案以固定 HPO 候选约束 Qwen3-8B 或更小模型，
保留原文证据和字符边界；是否引入微调由同协议验证结果决定。

外层 16 篇已经用于比较和错误分析，属于开发留出集，不是未触碰测试集。
A/B 输入没有用于学习别名或选择当前模型。

## 复现

从仓库根目录运行，令 `PATIENTPHEX_DATA` 指向已解压的 `official_v1` 目录：

```bash
python reproduction/patientphex_532512/run_baselines.py \
  --train "$PATIENTPHEX_DATA/PatientPheX-V1-A/PatientPheX-train.jsonl" \
  --hpo "$PATIENTPHEX_DATA/PatientPheX-V1-A/hp.obo" \
  --a "$PATIENTPHEX_DATA/PatientPheX-V1-A/PatientPheX-A.jsonl" \
  --b "$PATIENTPHEX_DATA/PatientPheX-V1-B/PatientPheX-V1-B.jsonl" \
  --output-dir reproduction/patientphex_532512/runs/baselines_replay

python reproduction/patientphex_532512/analyze_baselines.py \
  --run-dir reproduction/patientphex_532512/runs/baselines_v1 \
  --output reproduction/patientphex_532512/runs/baselines_v1/paired_bootstrap_replay.json
```

输出采用独占创建，复现实验应使用新目录；已完成的结果和原始数据不覆盖。
